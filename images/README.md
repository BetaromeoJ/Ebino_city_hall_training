# images フォルダ

このフォルダに以下のファイル名で画像を置くと、
ポータル上の「画像準備中」の枠が自動で写真に差し替わります。
（置かない間は枠のまま表示されるので、画像が無くても研修は進められます）

| ファイル名 | 使用場所 | 推奨サイズ |
|---|---|---|
| hero.jpg | トップ（研修の雰囲気／えびの市の写真） | 横1200×縦900 程度 |
| work1-sample.jpg | ワーク1の完成見本チラシ | 縦長 800×1130 程度 |
| before.jpg | 伝わるデザイン：改善前 | 縦長 800×1130 程度 |
| after.jpg | 伝わるデザイン：改善後 | 縦長 800×1130 程度 |
| photo-before.jpg | 写真1枚から：元の写真 | 横1200×縦800 程度 |
| photo-after.jpg | 写真1枚から：加工後 | 横1200×縦800 程度 |
| wada.jpg | 講師紹介：和田 倫周 の顔写真 | 正方形 600×600（丸く切り抜いて表示）**配置済み** |
| nakano.jpg | 講師紹介：中野 信盛 の顔写真 | 正方形 600×600（丸く切り抜いて表示）**配置済み** |
| book-cover.jpg | 著作紹介：書影 | 幅700px **配置済み** |

※ ファイル名は必ず小文字・半角で、上の表のとおりにしてください（GitHub Pagesは大文字小文字を区別します）。
※ 1枚あたり 500KB 以下を目安に書き出すと、庁内PCでも軽く表示されます。
